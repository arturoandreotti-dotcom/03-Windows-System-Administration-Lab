# Windows System Administration Lab

## Overview

A hands-on IT portfolio project focused on developing practical Windows system administration skills in a virtualized environment.

The project covers Windows services, scheduled tasks, PowerShell scripting, system configuration, and administrative troubleshooting.

## Technologies

- Windows 11 Enterprise Evaluation
- Oracle VirtualBox
- PowerShell
- Visual Studio Code
- Git and GitHub

## Labs

### Scheduled Task Automation

Developed a PowerShell script to record execution timestamps and configured Windows Task Scheduler to execute it daily.

**Key activities:**
- Created and tested a PowerShell logging script.
- Configured a scheduled task with a daily trigger.
- Troubleshot execution policy and battery-related restrictions.
- Verified successful task execution and the next scheduled run.

**Documentation:** [Scheduled Task Automation](docs/scheduled-task-automation.md)

**Script:** [Write-ExecutionLog.ps1](scripts/Write-ExecutionLog.ps1)
